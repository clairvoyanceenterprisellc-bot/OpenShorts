OpenShorts — Privacy Policy

Last updated: November 2026

OpenShorts is a self-hosted tool that runs on a single person's own machine. There is no central server, no hosted backend, and no analytics or tracking operated by a third party — everything described below happens locally on that machine, under that person's own control.

What's stored, and where

  • Video files (downloaded source recordings and cut clips) are stored only on the local machine's disk, in ~/.openshorts/. They are never uploaded anywhere except the specific platform (YouTube, TikTok, Instagram) the operator explicitly chooses to post a given clip to.
  • OAuth access tokens and refresh tokens for connected platforms are stored locally in a SQLite database on the same machine. They are used only to make API calls to that platform on the operator's own behalf (uploading/posting content, checking view/stats). They are never transmitted to any third party.
  • No analytics, telemetry, or usage tracking of any kind is collected by this tool itself.

Data sent to connected platforms

When a clip is posted, the video file and a generated title/description are sent directly to that platform's own official API (e.g. TikTok's Content Posting API, YouTube Data API). Each platform's own Privacy Policy governs how they handle that data once received. This tool does not add any additional data collection on top of what each platform's API inherently requires for posting (e.g. an access token proving the operator's own authorization).

No data sharing

Nothing processed by this tool is sold, shared, or disclosed to any third party outside of the specific connected platform a clip is explicitly posted to.

Deleting your data

Since everything is stored locally, deleting ~/.openshorts/ removes all locally stored video files, tokens, and metadata. Disconnecting a platform in the dashboard's Connections tab clears that platform's stored access token immediately.
